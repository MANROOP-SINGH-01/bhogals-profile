# Manroop Singh Bhogal — Portfolio

A 1:1 replica of the agentic AI engineer portfolio, customized for **Manroop Singh Bhogal**.

## Features

- **HUD Loading Screen**: Real-time percentage counter with HUD corner borders and branded nameplate.
- **Hero Section**:
  - Animated `TextScramble` title ("Manroop Singh" & "Bhogal").
  - Monogram navigation (`MSB.`) with breath animation and glassmorphism.
  - Interactive retro terminal widget with command support (`help`, `whoami`, `projects`, `gaming`, `neofetch`, `contact`).
  - Web Audio API keyboard typing sound engine with sound toggle switch (persisted in `localStorage`).
  - 3D WebGL background canvas with ambient particle mesh.
- **Player Profile**:
  - Interactive 3D tilt card with gloss sweep effect.
  - Clickable Creeper easter egg avatar with blink animation.
  - Interactive "Product Readiness" SVG Radar Chart with project switcher.
  - Track record achievement cards with gold badge icons.
- **Work Showcase**:
  - Featured projects with tags, status, and animated audio waveforms.
- **Archive**:
  - Filterable list of repositories, experiments, and open-source packages.
- **Skills Matrix**:
  - Categorized HUD skill badges (Languages, Frameworks, Cloud & DevOps, AI & LLMs, Tooling).
- **Competitive Gaming**:
  - Valorant Contenders Premier captain statistics and rank display.
- **Contact & Footer**:
  - Contact information, social links (GitHub, LinkedIn, X/Twitter), and marquee banner.

## Quick Start

### 1. Run with Node.js
```bash
npm run dev
# or
npm start
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Static Hosting
This project is self-contained with static assets and can be hosted directly on **Vercel**, **GitHub Pages**, **Netlify**, or **Cloudflare Pages** by deploying the directory as a static site.
